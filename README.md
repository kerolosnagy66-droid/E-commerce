# 🛒 Modern E-commerce Platform

A professional, high-performance e-commerce web application built with **React**, featuring dynamic category management, real-time product fetching, and a premium user interface.

![Home Page Mockup](https://raw.githubusercontent.com/username/project/main/public/screenshots/home.png)

## ✨ Features

- **🛍️ Dynamic Category Navigation**: Seamlessly browse products across various categories like Electronics, Fashion, Beauty, and more.
- **📱 Premium Product Sliders**: Engaging product displays with autoplay, touch-swipe support, and responsive layouts.
- **🔐 Secure Authentication**: Polished Login and Registration flow with real-time validation and persistent sessions.
- **📄 Detailed Product Pages**: Comprehensive product information including pricing, descriptions, and specifications.
- **⚡ Performance Optimized**: Centralized data fetching using custom hooks (`useFetch`) and reusable UI components.
- **🎨 Modern Design System**: A clean, glassmorphic aesthetic with a deep blue professional color palette.

## 🛠️ Tech Stack

- **Frontend**: React 19, React Router 7
- **Styling**: Vanilla CSS (Custom Variable System)
- **API**: [DummyJSON](https://dummyjson.com/)
- **Libraries**:
  - `Swiper` (Product Sliders)
  - `React Icons` (Visual Elements)
  - `React Hot Toast` (Notifications)
  - `Joi` (Form Validation)

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+)
- npm

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/e-commerce.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm start
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

## 📂 Project Structure

```bash
src/
├── components/      # Reusable UI components (Header, Footer, Sliders)
├── context/         # Context API for state management
├── hooks/           # Custom React hooks (useFetch)
├── pages/           # Main application pages
├── img/             # Static assets and images
└── index.css        # Global styles and design tokens
```
