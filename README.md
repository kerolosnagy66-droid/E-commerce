# E-commerce Platform - Modern Gadget Store

A premium e-commerce application built with React, focusing on a clean and optimized user experience for electronics and tech gear.

## Key Features
- **Modern UI/UX**: Premium design using custom CSS variables (Gradients, Glassmorphism).
- **Global Search**: Search for products from any page instantly.
- **Dynamic Shop**: Category filtering and real-time product sorting.
- **Full Shopping Flow**: Complete wishlist, cart management, and checkout process.
- **Authentication**: Secure Login and Registration with form validation.
- **Responsive**: Fully optimized for mobile, tablet, and desktop views.

## Tech Stack
- **Frontend**: React.js (v18+)
- **Routing**: React Router Dom
- **State Management**: Context API (Auth, Cart, Wishlist)
- **Data Source**: dummyjson.com (Product API)
- **Icons & UI**: React Icons, Swiper.js, React Hot Toast

## Development
To run this project locally:

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the dev server:
   ```bash
   npm start
   ```

## Production
To create an optimized build:
```bash
npm run build
```
